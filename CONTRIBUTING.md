# Panduan Berkontribusi

Terima kasih ingin berkontribusi pada proyek Food Rescue Indonesia! 
Harap perhatikan beberapa panduan berikut:

1. Buat branch baru dari `development` dengan format `feat/nama-fitur` atau `fix/nama-bug`.
2. Pastikan Anda menjalankan `pnpm tsc --noEmit` untuk mengecek tipe TypeScript sebelum commit.
3. Tulis pesan commit secara deskriptif (mengikuti standar *Conventional Commits*).
4. Buat Pull Request ke branch `development`.
