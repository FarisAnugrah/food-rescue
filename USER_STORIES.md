# User Stories

## Consumer
- As a consumer, I want to see nearby food listings on a map so I can find close options.
- As a consumer, I want to filter by category and price to find what I like.
- As a consumer, I want to pay securely via e-wallet so checkout is fast.
- As a consumer, I want a QR code receipt so I can quickly claim my food.

## Merchant
- As a merchant, I want to post a "surprise bag" quickly so I don't waste time itemizing.
- As a merchant, I want to set a pickup time window so customers don't disrupt peak hours.
- As a merchant, I want to scan a customer's QR code to verify their order instantly.
- As a merchant, I want to see how much food I've saved to track my impact.

## Admin
- As an admin, I want to review new merchant applications to ensure quality control.
- As an admin, I want to view platform-wide transaction volume to track growth.
