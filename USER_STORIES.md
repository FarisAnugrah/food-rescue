# User Stories

## Consumer
- As a consumer, I want to see nearby food listings on a map so I can find the closest options.
- As a consumer, I want to filter by category, price, and halal/non-halal so I can find food that suits me.
- As a consumer, I want to see the pickup time window so I know when to collect my food.
- As a consumer, I want to see the estimated weight (kg) per bag so I know what I'm getting.
- As a consumer, I want to pay securely via e-wallet/QRIS so checkout is fast.
- As a consumer, I want a QR code receipt so I can quickly claim my food at the merchant.
- As a consumer, I want to see my personal impact (kg food saved, CO2 prevented) so I feel good about my contribution.
- As a consumer, I want to earn badges based on my rescue activity to stay motivated.
- As a consumer, I want to review and rate merchants after pickup so others can make informed decisions.
- As a consumer, I want to receive a pickup reminder 30 minutes before the window closes so I don't miss it.
- As a consumer, I want to see the global impact counter (total kg saved) so I see the community's collective effort.

## Merchant
- As a merchant, I want to register and submit my business documents so I can get verified on the platform.
- As a merchant, I want to post a "surprise bag" quickly so I don't waste time itemizing each food.
- As a merchant, I want to post specific items when I know exactly what surplus I have.
- As a merchant, I want to set a pickup time window so customers don't disrupt my peak hours.
- As a merchant, I want to label my food as halal or non-halal to be transparent.
- As a merchant, I want to set a minimum quantity (min 5kg total) to make rescue logistics worthwhile.
- As a merchant, I want to scan a customer's QR code to verify their order instantly at pickup.
- As a merchant, I want to see my analytics (revenue, food saved, CO2 prevented, rating) to track my performance.
- As a merchant, I want to earn a "Food Waste Warrior" badge when I reach rescue milestones.
- As a merchant, I want to receive notifications when a new order comes in so I can prepare the food.
- As a merchant, I want expired listings to auto-close so I don't have to manage them manually.

## Admin
- As an admin, I want to review merchant applications and documents to ensure quality and legitimacy.
- As an admin, I want to approve or reject merchants with a reason so they can improve their application.
- As an admin, I want to flag or take down listings that violate food safety rules.
- As an admin, I want to view platform-wide impact metrics (kg saved, CO2 prevented, transactions) to track growth.
- As an admin, I want to see a merchant leaderboard (top rescuers) to identify and reward active participants.
- As an admin, I want to manage food safety guidelines content that merchants must follow.
- As an admin, I want to process refunds for disputed orders to maintain consumer trust.

## Future: Volunteer
- As a volunteer, I want to sign up as a delivery helper so I can assist in distributing food to communities in need.
- As a volunteer, I want to see my personal impact (deliveries completed, kg distributed) to track my contribution.
